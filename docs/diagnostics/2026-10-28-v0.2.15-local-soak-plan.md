# RemoteOrbit v0.2.15 Local Soak Plan

Date: 2026-10-28

## Decision

Do not publish v0.2.15 yet.

Build a local DMG from the current v0.2.15 candidate, install it on the owner's Mac, and run it for a longer real-world observation period before deciding whether to merge/tag/publish the release.

## Candidate identity

- branch: `codex/release-v0.2.15`
- marketing version: `0.2.15`
- build: `44`
- target architecture: Universal 2
- public release state: NOT RELEASED

The local soak candidate is not a claim that the remaining audio-continuity root cause is fixed. Task 038-B remains `NARROWED_NOT_ESTABLISHED`.

## Observation mode

Continuity evidence remains opt-in:

`REMOTE_ORBIT_CONTINUITY_EVIDENCE=1`

The candidate should be used naturally for an extended period. Do not manufacture weak Bluetooth, artificial load, synthetic trigger patterns, or deliberate underruns.

Preserve enough runtime identity to bind later logs to the exact candidate:

- app path;
- bundle ID;
- version/build;
- executable SHA-256;
- embedded `RemoteOrbitDiagnosticSourceHead`;
- diagnostic environment;
- observation window.

## Local packaging gate

Before installing the candidate:

1. reconcile/fetch the live release branch;
2. use one clean local release worktree;
3. run `swift test`;
4. run `remote-orbit/run-self-tests.sh`;
5. run the established driver/app/DMG packaging flow;
6. verify the app is `com.lost0rz.RemoteOrbit`, `0.2.15 (44)`, arm64+x86_64, codesign-valid, and stamped with the exact candidate head;
7. verify the DMG mounts and contains the expected app/documentation structure;
8. calculate and record the DMG SHA-256.

A packaging-only corrective is allowed only when a fresh packaging failure directly requires it and it does not change product runtime semantics.

## Soak boundary

During the observation period:

- no merge of PR #25;
- no `v0.2.15` tag;
- no GitHub Release;
- no speculative audio/BLE corrective;
- no 038-C/D/E/F activation.

After sufficient real-world use, review the accumulated logs and user-observed behavior. Only then decide whether the same candidate is acceptable for formal publication or whether another corrective cycle is justified.
